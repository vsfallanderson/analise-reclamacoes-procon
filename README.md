# Análise de Reclamações PROCON 2024

## Objetivo
Analisar padrões de reclamações registradas no PROCON nacional em 2024,
identificando estados, empresas, problemas recorrentes e perfil dos consumidores.

## Fonte dos dados
Dados Abertos do Governo Federal — dados.gov.br
Dataset: Cadastro Nacional de Reclamações Fundamentadas 2024

## Ferramentas
- PostgreSQL
- DBeaver

## Principais insights
- CE, SP e GO concentram o maior volume de reclamações
- 65% das reclamações não foram atendidas pelas empresas
- Cobrança indevida é o problema mais recorrente — aparece em duas
  categorias diferentes somando 36% do total
- Consumidores entre 41 e 70 anos representam a maioria das reclamações
